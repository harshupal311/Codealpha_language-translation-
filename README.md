

Language Translation Tool
Overview

This project is a simple Language Translation Tool that allows users to translate text from one language to another using the Google Translate API.

Features:

•Enter text to translate.
•Select the source language.
•Select the target language.
•Translate text using the Google Translate API.
•Display the translated text.
•Copy the translated text.
•Listen to the translated text using Text-to-Speech.
•Technologies Used
•HTML
•CSS
•JavaScript
•Google Translate API

How It Works:

•Enter the text you want to translate.
•Choose the source language.
•Choose the target language.
•Click the Translate button.
•The translated text is displayed on the screen.
•Use the Copy button to copy the translated text or the Speak button to hear it.
Setup
•Download or clone the project.
•Get a Google Translate API key from Google Cloud.
•Replace YOUR_GOOGLE_API_KEY in the code with your API key.
•Open index.html in a web browser.

Project Outcome:

•This application provides a simple and user-friendly way to translate text between different languages while also offering copy and text-to-speech features for better usability.
